# Enable Anonymous sign-in

One console step. Nothing else in Firebase needs to change for name-only entry.

1. Open the [Firebase console](https://console.firebase.google.com/) for project `thirstyfrog-e2aed`.
2. Go to **Authentication → Sign-in method**.
3. Open **Anonymous**, turn it on, and save.

Database rules are not part of this step. The proposed rules file is `db/rules.golf.betting.json`. Do not deploy it from here unless you mean to publish that file.
